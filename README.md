## 실제 센터 동선 참고

사용자가 제공한 사진과 배치 설명을 바탕으로 입구 정면 접수데스크, 입구 오른쪽 교육실, 접수대 앞 혈압계 두 대, 왼쪽 커피머신·정수기를 배치했습니다. 종합상담실은 정면, 트라우마상담실은 왼쪽 복도, 근골격계질환상담실은 오른쪽 복도 끝으로 구성했습니다. 뇌심혈관 상담실 입구는 오른쪽 혈압계 왼쪽입니다. 정확한 치수나 평면도를 재현한 것은 아닙니다.

작업환경상담실은 실제 센터에 별도 방이 없으며 사용자의 요청에 따라 왼쪽 복도 끝에 가상 배치했습니다. 직무스트레스 상담실의 실제 위치는 확인되지 않아 로비에 임의로 배치하지 않고 메뉴로 접근하는 가상 상담 공간으로 유지했습니다.

근골격계질환상담실에 운동기구·짐볼·덤벨·세라젬·안마기 모형과 기구별 안내를 추가했습니다. 안마기·세라젬 자세 체험은 캐릭터의 가상 자세일 뿐 실제 기기의 작동·측정·치료를 제공하지 않습니다. 사진 원본을 게시한 것이 아닌 사진을 참고해 만든 3D 모형입니다.

- Three.js 기반 3D 가상 센터, 캐릭터 이동·앉기·옷 색상 선택
- 여섯 개의 독립된 상담실: 종합상담, 뇌심혈관계질환예방상담, 근골격계질환상담, 작업환경컨설팅, 직무스트레스, 트라우마상담
- 방 입장 시 해당 방 확대, 방문자 의자 착석, 가상 안내 직원과 주제 선택형 대화, 로비로 복귀
- 마음 쉼터: 숨 고르기
- 건강 우체통: 창작 응원 편지 받기, 개인 편지 작성·보관·삭제
- 검진 상담실: 가상 결과지로 상담 준비 체험
- 일터 체험실: 건강관리 물건 찾기
- 건강 게시판: 센터 OX 퀴즈
- 작은 약속과 여섯 가지 브라우저 도장 모으기
- 안내 데스크: 전화 상담 및 예약 문의
- 공식 홈페이지와 HWP 신청서 3종 다운로드

도장과 작성한 개인 편지만 이용자의 브라우저 localStorage에 저장합니다. 선택한 답변이나 편지는 서버에 전송하지 않습니다. 공용 기기에서는 편지 보관함을 삭제해 주세요. 온라인 예약 접수 기능은 없으며 대표전화로 연결합니다.

실제 센터 구조를 재현한 공간이 아닌 가상의 3D 체험 공간입니다. 각 방의 직원은 실제 사람이나 실시간 AI 상담이 아닌 미리 작성된 선택형 안내입니다. 대화 주제는 저장·전송하지 않습니다. 실제 상담은 전화로 문의합니다. 응원 편지는 창작 콘텐츠이고 검진 체험은 가상 사례입니다. 기관의 공식 운영·승인 여부는 별도로 확인해야 합니다.

화면을 누르거나 방향키/WASD, 화면의 방향 버튼으로 이동합니다. 체험 공간이나 하단 체험 메뉴를 누르면 활동이 열립니다. 별도 서버·외부 API 키 없이 GitHub Pages에서 실행되며 Three.js와 Lucide는 vendor 폴더에 포함되어 있습니다. 라이선스는 해당 폴더에서 확인할 수 있습니다.
