# 건강정원

대전근로자건강센터 서비스를 소개하는 체험형 웹사이트입니다.

## GitHub Pages

별도의 빌드, 서버, Google Drive 연결이 필요하지 않습니다.
저장소 Settings > Pages에서 Deploy from a branch, main, /(root)를 선택합니다.

## 인물과 재질

`center-visuals.js`는 관절형 인물, 둥근 모서리의 가구, 직물·나뭇결 재질과 잎 모양 식물을 구성합니다. 실사 인물의 복제 모델이 아닌 부드러운 스타일의 캐릭터입니다. 걷기와 착석 시 무릎 관절을 사용하며, 정적인 부품은 Three.js의 `BufferGeometryUtils`로 합쳐 렌더링 호출을 줄입니다. 물건 배치와 커피머신·정수기의 통로 방향은 유지합니다.

모델 경계와 관절·기기 모형 검사는 `node tests/visual-models.mjs`로 실행합니다.

## 모바일 화면

`mobile-view.css`와 `mobile-view.js`가 실제 표시 영역(`visualViewport`)과 상단 높이를 기준으로 3D 화면 높이를 맞춥니다. 휴대폰 세로·가로 방향, 브라우저 주소창 높이 변화와 안전 영역에 대응하며, 이동 버튼과 공간 선택을 화면 안에 배치합니다. 모바일은 상담실 선택 메뉴·접수/대기실 바로가기와 접을 수 있는 화면 도구를 사용합니다. 상담실 안내는 3D 아래에 이어지고, 가로 화면의 접수 대화는 대화와 응답을 두 열로 배치합니다. 데스크톱 탐색 방식과 센터 배치는 유지합니다.

## 실내 산책 시점

혈압 측정 후 상담실에 돌아와 착석하면 혈당 측정 안내가 자동으로 이어집니다. 방문자는 앉은 채 왼손 검지를 내밀고, 안내 직원이 혈당계와 시험지를 손가락 옆으로 가져오는 동작을 보여줍니다. 채혈·바늘·출혈 묘사는 넣지 않았습니다. 확대 화면에는 고정 예시 `92 mg/dL`와 ‘측정값은 예시입니다’, ‘실제 검사·진단 아님’을 표시하며 건강 상태를 판정하거나 수치를 저장·전송하지 않습니다. 종료 안내 후 손을 내리고 계속 앉아 있고, 직원과 기기는 제자리로 돌아갑니다. 중지·이동·퇴실 시 손가락·직원·기기 상태를 복원합니다. `node tests/cardio-glucose-scene.mjs`로 착석 유지·왼손 검지·시험지 접점·예시값·종료·취소를 검사합니다.

혈당 측정 뒤에는 콜레스테롤 측정 체험이 자동으로 이어집니다. 방문자가 앉은 채 왼손 네 번째 손가락을 내밀면 코드 번호 확인, 스트립 삽입, 손가락 준비, 스트립 접촉, 결과 대기 순서를 짧게 보여줍니다. 채혈·바늘·출혈은 묘사하지 않습니다. 안내 직원이 자리로 돌아가 앉은 뒤 확대 화면에서 총콜레스테롤 `168`, 중성지방 `150`, 저밀도지단백콜레스테롤 `60`, 고밀도지단백콜레스테롤 `100 mg/dL`을 차례로 표시합니다. 모든 수치는 고정된 측정 예시일 뿐 실제 검사·진단·건강 판정이 아닙니다. 결과 말풍선은 기기 화면의 항목명과 수치를 가리지 않는 빈 공간에 배치합니다. 종료 후 방문자와 직원은 계속 착석합니다. `node tests/cardio-cholesterol-scene.mjs`로 단계 순서·네 번째 손가락·스트립·네 결과·직원 착석·방문자 착석·취소를 검사합니다.

‘당화혈색소 검사요’를 선택하면 복부둘레·신장체중·혈압·혈당의 기존 기본검사 동선을 마친 뒤 당화혈색소 측정 체험으로 이어집니다. 안내원이 최근 2~3개월의 평균적인 혈당 조절상태를 확인하는 검사임을 설명하고, 방문자는 앉은 채 왼손 네 번째 손가락을 내밉니다. 확대된 기기 화면에는 고정 예시 `HbA1c 5.6%`와 ‘측정 예시’, ‘실제 검사·진단 아님’을 함께 표시합니다. 채혈·바늘·출혈은 묘사하지 않으며 종료 후 방문자와 안내원은 계속 앉아 있습니다. 실제 검사 결과를 생성·저장·전송하거나 건강 상태를 판정하지 않습니다. `node tests/cardio-hba1c-scene.mjs`로 단계 순서·네 번째 손가락·예시값·직원 착석·방문자 착석·취소를 검사합니다.

신장·체중 측정 후 의자에 앉으면 안내원의 말에 따라 로비의 접수대 옆 자동혈압계로 이동합니다. 의자에 앉아 안정 안내를 보고 오른팔을 삽입한 뒤, 왼손 검지로 ‘시작’을 누르는 동작을 보여줍니다. 표시창이 확대되고 빨간 가압 숫자가 올라간 뒤 고정된 가상 예시 `118 / 76 mmHg`, 맥박 `72회/분`을 표시합니다. 실제 검사·건강 판정이 아니며 저장·전송하지 않습니다. 체험에서는 안정 시간을 짧게 보여주지만 실제 측정 전 5분 이상 안정하도록 안내합니다. 이후 자동으로 상담실에 돌아와 착석합니다. 이동·중지·퇴실 시 팔·손가락과 표시창을 복원하고, 접수 자동 인사는 이 동선 중 중복 실행하지 않습니다. `node tests/cardio-bp-scene.mjs`로 공간 전환·동작·숫자·복귀·취소를 검사합니다.

안내 대화는 3D 화면 중앙의 고대비 말풍선으로 표시합니다. 진행 중 안내는 읽을 시간 후 자동으로 사라지며 닫을 수도 있고, 상담실 패널에도 남습니다. 일반 상담실의 선택형 답변과 접수·상담지 질문도 중앙 말풍선 또는 중앙 대화창으로 읽을 수 있습니다.

뇌심혈관 예방상담실에서는 방문자 의자에 앉으면 안내원이 자동으로 인사하고 혈압·혈당·콜레스테롤, 당화혈색소, 동맥경화 검사 중 원하는 항목을 선택합니다. 기본검사 안내 후 ‘일어나서 복부둘레 재기’를 누르면 방문자가 양팔을 어깨높이로 들고, 직원이 책상을 돌아 옆으로 이동해 줄자로 재는 동작을 합니다. 이후 팔을 내리고 직원은 자리로 돌아갑니다. 중지·이동·재착석·퇴실 시 자세를 복원하며, 실제 측정값이나 검사 결과는 생성·저장하지 않습니다. `node tests/cardio-scene.mjs`로 단계, 자세, 이동 경로, 취소와 리소스 정리를 검사합니다.

복부둘레 동작이 끝나 직원이 자리에 돌아오면 신장·체중 측정 안내가 자동으로 이어집니다. 방문자는 책상 왼쪽 통로를 따라 기기로 이동해 신발을 벗어 옆에 두고, 발판 위에서 정면을 바라봅니다. 머리 위 측정판이 내려왔다 복귀하면 ‘내려와 주세요’ 안내 후 내려와 신발을 신고 상담 의자에 자동 착석합니다. 재착석 시 첫 인사를 반복하지 않으며, 이동·중지·퇴실 시 신발과 측정판 위치를 복원합니다. 실제 신장·체중 수치는 만들거나 저장하지 않습니다. `node tests/cardio-height-scene.mjs`로 전체 단계와 복원 동작을 검사합니다.

접수대 앞에 걸어오면 가상 안내원이 자동으로 인사합니다. 첫 방문·재방문·방문 여부 불명확 응답에 따라 대화가 나뉘며, 재방문 확인은 고정된 체험용 이름 ‘대전이’ 또는 예시 번호만 선택합니다. 실제 이름·전화번호 입력이나 방문 기록 조회·저장·전송은 하지 않습니다. 대기실·자동혈압계 위치 이동 및 다른 상담 분야 안내도 연결합니다. 대화를 닫고 접수대 앞에 머물 때는 다시 열리지 않으며, 충분히 멀어졌다 돌아오면 다시 인사합니다. 접수데스크 선택으로 수동 시작도 가능합니다. `node tests/reception-flow.mjs`로 분기와 접근 범위를 검사합니다.

첫 방문 안내의 ‘대기실로 가기’는 소파 옆까지 이동한 뒤 착석하고, 상담지 작성 안내의 ‘네 / 아니오’를 표시합니다. 소파 클릭이나 대기실 소파 버튼, 근처의 앉기 버튼으로도 이용합니다. ‘네’는 앞장 작성 항목 13개와 뒷장 개인정보 동의서 확인 항목만 보여줍니다. 성명·생년월일·건강정보 등의 실제 입력란은 없으며, 뒷장 체크는 안내 확인용으로만 동작하고 저장·제출하지 않습니다. 실제 동의서 문구나 법적 동의를 대신하지 않습니다. `node tests/intake-items.mjs`로 항목과 좌석 위치를 검사합니다.

첨부 사진을 참고한 크리스마스트리를 접수데스크 왼쪽 앞의 대기실 방향 빈 공간에 배치했습니다. 큰 별, 빨강·금색·은색 장식, 따뜻한 전구, 금색 리본과 선물상자를 입체 모형으로 구성했습니다. 커피머신·정수기와 출입문을 가리지 않고 접수대 중앙 이동 통로를 남기며, 전체 배치 보기와 모바일 화면에서도 위치를 확인할 수 있습니다.

뒷장 ‘안내데스크로 가기’를 선택하면 소파에서 일어나 접수대 앞까지 이동하고, 도착 후 ‘상담지를 다 작성하셨나요?’부터 대화를 이어갑니다. 검사·상담 소개 후 a~i 아홉 응답을 구분하며 뇌심혈관·근골격계·직무스트레스·작업환경/이어핏·직업트라우마 안내로 연결합니다. 이동을 중단하더라도 다음 접수 대화에서는 작성 후 안내를 이어갑니다. 이 상태는 현재 페이지 메모리에만 두며 실제 상담지 작성 완료나 접수·검사 결과를 기록하지 않습니다.

기본 화면은 캐릭터 뒤를 따라가는 실내 시점입니다. 캐릭터가 이동하면 카메라도 함께 이동합니다. 화면 드래그로 주변을 둘러보고, 방향키/WASD 또는 화면 방향 버튼으로 이동할 수 있습니다. 빈 바닥 클릭은 EasyStar.js 경로 탐색으로 이어지며 벽과 가구를 피합니다. 상담실 문 앞까지 걸어가면 방으로 들어갑니다.

화면 도구에서 1인칭, 전체 배치 보기, 확대·축소, 기본 시점 복원, 전체화면을 선택할 수 있습니다. 상담 의자에서는 직원이 보이는 어깨 너머 시점을 사용합니다. 3D 장면은 실제 센터와 동일한 치수의 건축 모델은 아닙니다.

## 실제 센터 동선 참고

사용자가 제공한 손그림 평면도를 기준으로 상단에 심리상담3·심리상담2·종합상담·심리상담1을 차례로 배치했습니다. 그 아래 가로 복도, 중앙 접수데스크, 오른쪽 위 근골격계질환 상담실, 오른쪽 아래 교육실, 접수대 오른쪽 뇌심혈관계질환 예방 상담실로 구성했습니다. 오른쪽 방들은 왼쪽 복도로 출입합니다. 방과 출입구 좌표는 `center-plan.js`에서 관리합니다. 도면의 상대적인 배치를 참고했으며 실측 치수는 아닙니다.

왼쪽 아래 대기 공간에는 L자 소파와 테이블을 두고, 그 위쪽에 정수기·커피머신·자동혈압계를 세로로 배치했습니다. 다른 자동혈압계는 뇌심혈관계질환 예방 상담실 문 바깥 접수대 오른쪽 끝 앞에 있습니다. 손그림의 색상은 시설 구분용이며 모형 색상은 사진을 참고했습니다.

작업환경컨설팅은 실제 센터에 별도 방이 없어 메뉴로 접근하는 가상 공간으로 유지합니다. 심리상담1·2의 직무스트레스·트라우마 안내 연결은 가상 체험용이며 실제 방별 담당 분야는 센터에 확인해야 합니다. 심리상담3에는 일반 상담 준비 안내를 제공합니다.

근골격계질환상담실에 운동기구·짐볼·덤벨·세라젬·안마기 모형과 기구별 안내를 추가했습니다. 안마기·세라젬 자세 체험은 캐릭터의 가상 자세일 뿐 실제 기기의 작동·측정·치료를 제공하지 않습니다. 사진 원본을 게시한 것이 아닌 사진을 참고해 만든 3D 모형입니다.

뇌심혈관질환 예방상담실은 추가 사진과 수정 요청에 따라 오른쪽에 검은 매트 침대와 동맥경화 검사기 카트, 왼쪽 모서리에 신장·체중 측정기를 배치했습니다. 왼쪽 앞 체성분 분석기는 삭제했습니다. 상담 책상 위에는 콜레스테롤·간이혈당·당화혈색소 측정기가 있습니다. `center-plan.js`의 `CARDIO_EQUIPMENT`가 로컬 위치와 책상 높이를 관리합니다. 장비는 외형과 절차 참고용이며 화면의 고정 예시는 실제 검사 결과가 아닙니다.

- Three.js 기반 3D 가상 센터, 캐릭터 이동·앉기·옷 색상 선택
- 평면도에 따른 일곱 공간: 심리상담1·2·3, 종합상담, 뇌심혈관계질환예방상담, 근골격계질환상담, 교육실 및 별도의 가상 작업환경컨설팅
- 방 입장 시 해당 방 확대, 방문자 의자 착석, 가상 안내 직원과 주제 선택형 대화, 로비로 복귀
- 마음 쉼터: 숨 고르기
- 건강 우체통: 창작 응원 편지 받기, 개인 편지 작성·보관·삭제
- 검진 상담실: 가상 결과지로 상담 준비 체험
- 일터 체험실: 건강관리 물건 찾기
- 건강 게시판: 센터 OX 퀴즈
- 작은 약속과 여섯 가지 브라우저 도장 모으기
- 안내 데스크: 전화 상담 및 예약 문의
- 공식 홈페이지와 HWP 신청서 3종 다운로드

도장과 작성한 개인 편지만 이용자의 브라우저 localStorage에 저장합니다. 선택한 답변이나 편지는 서버에 전송하지 않습니다. 공용 기기에서는 편지 보관함을 삭제해 주세요. 온라인 예약 접수 기능은 없으며 대표전화로 연결합니다.

실제 센터 구조를 재현한 공간이 아닌 가상의 3D 체험 공간입니다. 각 방의 직원은 실제 사람이나 실시간 AI 상담이 아닌 미리 작성된 선택형 안내입니다. 대화 주제는 저장·전송하지 않습니다. 실제 상담은 전화로 문의합니다. 응원 편지는 창작 콘텐츠이고 검진 체험은 가상 사례입니다. 기관의 공식 운영·승인 여부는 별도로 확인해야 합니다.

화면을 누르거나 방향키/WASD, 화면의 방향 버튼으로 이동합니다. 체험 공간이나 하단 체험 메뉴를 누르면 활동이 열립니다. 별도 서버·외부 API 키 없이 GitHub Pages에서 실행되며 Three.js와 Lucide는 vendor 폴더에 포함되어 있습니다. 라이선스는 해당 폴더에서 확인할 수 있습니다.
