# 건강정원

대전근로자건강센터 서비스를 소개하는 체험형 웹사이트입니다.

## GitHub Pages

별도의 빌드, 서버, Google Drive 연결이 필요하지 않습니다.
저장소 Settings > Pages에서 Deploy from a branch, main, /(root)를 선택합니다.

## 구성

- 창가: 숨 고르기
- 책상: 창작 응원 편지 열기
- 게시판: 센터 OX 퀴즈
- 러그: 작은 약속과 브라우저 도장 모으기
- 데스크: 전화 상담 및 예약 문의
- 공식 홈페이지와 HWP 신청서 3종 다운로드

도장 상태만 이용자의 브라우저 localStorage에 저장합니다. 선택한 답변과 건강정보는 서버에 전송하지 않습니다. 온라인 예약 접수 기능은 없으며 대표전화로 연결합니다.

기관의 실제 실내 사진이 아닌 생성 일러스트를 사용합니다. 편지는 창작 콘텐츠입니다. 기관의 공식 운영·승인 여부는 별도로 확인해야 합니다.
